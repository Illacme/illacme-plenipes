# 🌐 Ilacme Scriptorium 출판 팀에 관하여

**Illacme Scriptorium** 은 플랫폼 장벽을 허물고 모든 지식 창작자와 현대적 글쓰기 팀에게 데이터 주권을 완전히 되돌려줍니다.

---

## 🌟 우리의 비전

- **데이터 절대적 통제**: 물리 도서관은 항상 로컬 디스크에 유지됩니다.
- **전 프레임워크 호환**: 기존 작성 습관을 변경하지 않고, 한 번의 클릭으로 다양한 SSG 프레임워크 구조를 변환합니다.
- **AI 지능형 지원**: 고급 AI 컴퓨팅 허브를 활용하여 다국어 전역 배포를 손쉽게 완료합니다.
