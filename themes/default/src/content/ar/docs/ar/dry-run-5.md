# 📖 دليل الدخول السريع للمبدعين في 5 دقائق

أهلاً بك في **Illacme Plenipes**! سيُرافقك هذا الدليل خلال 5 دقائق لتتعلم كيفية استخدام مركز الحوكمة وإجراءات النشر.

---

## 🛠️ الخطوة الأولى: استكشاف مركز الحوكمة (لوحة حوكمة الأعمال)

افتح المتصفح للوصول إلى لوحة التحكم `http://127.0.0.1:43212/dashboard/`:

1. **الإعدادات الأساسية والصيانة (`general`)**: عرض معرف الهوية، والميتاداتيا الخاصة بالامتثال، ومركز تنظيف ذاكرة الحوسبة.
2. **التخطيط والتصميم والنمط (`layout`)**: إدارة شعارات العلامة التجارية، وتبديل الموضوعات البصرية (مثل Starlight)، وأوضاع النشر.
3. **الترجمة اللغوية والحوكمة (`localization_gov`)**: إعداد مصفوفة اللغات المتعددة، وقواعد المستوى الكتلي، ومخازن المصطلحات.

---

## ⚡ الخطوة الثانية: مزامنة فائقة السرعة عبر سطر الأوامر

بالإضافة إلى واجهة المستخدم الرسومية، يمكنك في أي وقت استخدام أوامر سطر الأوامر (CLI) لتنفيذ فحص تدريجي ومزامنة:

```bash
# 启动全量增量扫描与对齐
python3 plenipes.py --once

# 启动看门狗实时监听模式
python3 plenipes.py --watch
```

---

## 🎨 الخطوة الثالثة: المعاينة المحلية والتوزيع الشامل

بعد تشغيل خط أنابيب النشر، يمكنك بدء تشغيل منفذ خدمة المعاينة المحلية `43213` في أي وقت لمعاينة الموقع الثابت المُrendered بشكل أنيق في الوقت الفعلي!
