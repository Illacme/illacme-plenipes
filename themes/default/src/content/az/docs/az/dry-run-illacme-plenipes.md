# 🌌 Illacme Plenipes rəqəmsi nəşriyyat qalaktikasına xoş gəlmisiniz!

**Illacme Plenipes** — bu, kütləvi Markdown qeydləri və bilik bazaları üçün hazırlanmış sənaye səviyyəli rəqəmsal nəşr və bütün kanallara yayma mühərrikidir. İstər Obsidian, istərsə də Logseq kimi alətlər, istərsə də standart Markdown faylları ilə işləyərək, yalnız bir dəfə konfiqurasiya edildikdən sonra müasir statik blog (SSG) yaratmaq üçün tam funksionallıqda, çoxdilli və çoxtemalı uyğunlaşdırılmış "bir klik" rejimini aktivləşdirə bilərsiniz.

---

## 🚀 Əsas Xüsusiyyətlərinin Tam Mənzərəsi

> [!NOTE]
> Hər bir nəşr brendi (Imprint) müstəqil fiziki qovluqla əlaqələndirilir və bu, məlumatların fiziki izolyasiyasını və gizlilik təhlükəsizliyini tam şəkildə təmin edir.
### 1. Sıfır İnterferanslı Markdown Düğümü İdarəçiliyi
- **Native Dual-Link Dəstək**: Obsidian `[[WikiLinks]]` və etiket sistemləri ilə tam uyğunluq təmin edir.
- **Ağıllı Markdown Təmizləmə**: MDX sintaksisini avtomatik olaraq tanıyır, məxfi şərhləri süzgəcdən keçirir və orijinal mətnin təmizliyini qoruyur.

### 2. Hesablama qabiliyyəti mərkəzi və Block Cache parçalanması bölməsi
- **Səviyyəli hesablama qabiliyyəti ehtiyatı**: Ağıl hash yoxlaması, dəyişməz parçalar üçün sıfır hesablama qabiliyyəti təkrar sərfi.
- **Çoxmodel yük tarazlaşdırması**: LMStudio və Ollama yerli hesablama qabiliyyəti ilə bulud API-si arasında sızışsız keçidə dəstək.

```python
# 示例：系统内置的智能段落切片逻辑
def process_markdown_block(block_text: str, content_hash: str):
    if block_cache.has(content_hash):
        return block_cache.get(content_hash)
    
    refined_text = ai_engine.translate_and_enhance(block_text)
    block_cache.set(content_hash, refined_text)
    return refined_text
```

### 3. Çoxtəmənnəvi suveren qablaşdırma və bütün kanallar vasitəsilə paylanma
- **Bir kliklə bütün çərçivənin çevrilməsi**: Docusaurus, Starlight, VitePress, Nextra, Hugo və Hexo platformalarını dəstəkləyir.
- **Çoxlu cihaz üçün ümumi yayım**: GitHub Pages, Vercel, Netlify, Dev.to, Medium və digər bir çox platformaya bir kliklə paylanır.

## 💡 Hızlı Başlangıç Üç Adım Yöntemi

1. **Yaratma və ya dəyişdirmə**: Obsidian-da və ya istənilən redaktorla Markdown sənədini yazın.
2. **Ümumi yayım**: İnterfeysin sağ yuxarı küncündəki **🚀 Ümumi yayım** düyməsini klikləyin və ya CLI əmrindən istifadə edin.
3. **Nəticənin təqdimatı**: Yerli statik önizləmə veb-saytı anında yenilənir və oxucuların qarşısında dərhal görünür!
