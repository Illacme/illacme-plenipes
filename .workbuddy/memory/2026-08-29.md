## 白天分发抽屉 + 算力卡片精修 (commit e7cc5da)

**用户再次截图**："实时广播卡片视觉预览浅了，其他没变化"。分析发现前两轮 PATCH 改错地方：
- 图1 抽屉实际类名 = `.syndicate-drawer-overlay`（创建于 `syndicate.render.js:117`），不是 `.dispatch-hub-panel`。syndicate 抽屉用 inline `style.cssText` 硬编码 `rgba(15,17,26,0.96)`，CSS 需 `!important` 才能压过 inline style。
- 图2 调度卡片实际类名 = `.binding-terminal(.primary/.fallback)` + `.strategy-command-deck` + `.concurrency-guide-deck` + `.guide-step-card`，不是上一轮猜的 `.strategy-item`（根本不存在）。真根因：`.binding-terminal` 用 `var(--bg-card-rgb, 15, 23, 42)` 但 `--bg-card-rgb` 在 tokens.css 未定义，**fallback 永远深蓝灰**。

**本次两文件补丁**：
- `theme.light.overrides.css:609+` 加 `[data-theme="light"] .syndicate-drawer-overlay { background: rgba(255,255,255,0.96) !important; ... }` 强覆盖 inline
- `compute.strategy.css:488+` 重写 PATCH 用真实选择器

**未来教训（强化）**：当用户截图指错位置，**不能再凭截图关键字猜选择器**，必须：
1. 读 JS render 文件确认实际 `className`
2. 检查目标元素是否使用 inline style.cssText 硬编码背景
3. 验证目标 CSS 变量是否真的在 tokens.css 定义（避免被 fallback 误导）
