# ❓ 常见问题与排错手册 (FAQ)

本手册整理了创作者在初次上手与日常出版过程中的高频问题与自愈方案。

## 🔌 端口与服务规划

系统默认占用以下 4 个标准端口，请确保未被其他应用冲突占用：

| 端口 | 职责说明 |
|---|---|
| `43210` | 🔒 **单例进程锁**：防止后台被重复启动而破坏指纹账本 |
| `43212` | 🔌 **API 控制网关**：FastAPI 后端服务及治理中心前端承载 |
| `43211` | 🧙 **初始化向导**：初次配置引导向导端口 |
| `43213` | 🌐 **本地预览服务**：同步完成后内嵌静态站点预览服务器 |

## ❓ 常见疑问解答

### Q1: 默认品牌和自定义品牌有什么区别？
**A**: 默认品牌（`imprints/default`）是系统的官方展示橱窗。当使用默认品牌且搭配默认 Sovereign 主题时，系统默认解锁**全量高级专业版功能**，方便用户完整体验系统全貌；而当您新建自定义出版品牌时，功能将遵循社区版与商业授权规划。

### Q2: 修改了原稿，为什么没有重新消耗 AI Token？
**A**: 系统内置了**段落级影子缓存 (BlockShadowCache)**。每次同步时会对文档中每一个段落进行指纹计算，未做修改的段落将直接从本地缓存秒级读取，只有真正发生修改的段落才会发起 AI 翻译调用。

### Q3: 如何清空缓存或强制全量重编译？
**A**: 
- **命令行**：运行 `python3 plenipes.py --sync --force` 强行重编。
- **治理中心**：进入「基础配置」→「存储适配」→ 点击「🧹 立即执行全量缓存清理 (GC)」。

### Q4: 本地模型（Ollama / LMStudio）出现 400 错误或卡住怎么办？
**A**: 
1. 检查本地模型服务是否已启动（如 LMStudio 服务已开启 Local Server）。
2. 在治理中心将 `max_tokens` 适当增大（推荐 $\ge 4096$），以便留足本地模型的思维链（Thinking Process）输出空间。
