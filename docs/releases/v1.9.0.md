## ✨ v1.9.0 核心更新亮点

### 🤖 1. AI 出版主编智能体与开放 MCP 协议
* **14 项出版自治工具**：集成全站就绪度巡检、知识星谱语义检索与选题策展、双人播客合成、数字书籍装订、封面视觉生成与绑定、死信队列诊断与一键重试。
* **多轮会话记忆与工作区感知**：自动按品牌持久化近期多轮上下文（支持 `/clear` 重置），并将当前视图与编辑原稿注入智能体上下文。
* **安全边界与写前快照回滚**：非自动驾驶模式下对写盘/封面绑定/队列重试触发人类在环（HITL）审批，并为写盘操作自动留存快照支持一键撤销。
* **标准 MCP Server（Tools + Resources + Prompts）**：`/api/agent/mcp/rpc` 支持外部智能体（Cursor / Claude Desktop / Antigravity）直连读取文库索引、知识星谱与品牌配置；点击面板 `🔌 MCP 协议` 徽章即可一键复制客户端配置。

### 🎙️ 2. 双人伴读播客与全链路音频消歧
* **路径限定消歧**：对 `docs/index.md` 与 `blog/index.md` 等子目录同名文稿全链路采用路径限定标识（`docs__index`），彻底避免覆盖与播放串台。
* **跨主题伴读播放器与 RSS 2.0**：支持 Sovereign / Universal 主题与 EPUB/WebBook 内嵌音频播放器、章节时间戳与播客 RSS 订阅源生成，支持 R2/S3/OSS/COS 云存储转储。

### 📚 3. 多品牌物理隔离与跨模块数据一致性
* **多品牌隔离升级**：数字装订译文缓存、书架输出目录（`dist/books/{imprint_id}`）以及 `ImageHub` 封面生成落盘路径全面按当前激活品牌动态隔离，同时向下兼容 `default` 品牌。
* **文库移动/销毁全域联动**：原稿重命名、移动或销毁时原子同步 SQLite 元数据账本、知识星谱节点及入边、静态产物及伴读音频。
* **跨视图 UX 整合**：优化左侧领航仪交付物直达、渐进式出版模式提示与抽屉互跳入口。
