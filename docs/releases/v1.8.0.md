## 🛡️ 首次运行安全信任与避坑指南 (消除系统拦截阻力)

由于个人独立分发软件未购买高昂的企业商业商业证书，操作系统首次运行可能会弹出安全防护提示，请按以下极简指引放行：

### 🍎 macOS 首次运行提示“已损坏，无法打开”或“未经验证的开发者”
* **方案 A（极简首选，双击自愈）**：
  在 DMG 镜像或解压包中，直接**双击运行「双击修复无法打开.command」**脚本，系统将全自动清除 macOS Gatekeeper 的隔离属性。
* **方案 B（命令行一键直达）**：
  将应用拖入 Applications 目录后，打开 Terminal 运行：
  ```bash
  xattr -cr /Applications/Illacme-Plenipes.app
  ```
* **方案 C（访达免命令行）**：
  在「访达」➔「应用程序」中，**按住 Control 键并右键点击** `Illacme-Plenipes.app`，选择「打开」，在二次安全确认弹窗中再次点击「打开」即可永久加入系统信任。

### 🪟 Windows Defender SmartScreen 蓝色警告窗口
* 点击警告窗口中的 **「更多信息 (More info)」** 文本链接；
* 在随后弹出的按钮中点击 **「仍要运行 (Run anyway)」** 即可启动。

## ✨ v1.8.0 核心演进与重大特性详解

### 1. 语义化版本唯一真理源（Rule 18 物理铁律）
* **真理源绝对统一部署**：全系统严格对齐 `core.__version__ = "1.8.0"`，全面消除过往历史开发过程中遗留的离散内部代号；
* **主题母本纯净隔离**：全面清理主题示例中的死版本号，动态渲染版本感知，遵循 Rule 13 母本零污染规范。

### 2. 桌面端打包流水线资产瘦身与原装 DMG 镜像
* **资产物理隔离暂存（Asset Staging）**：重构打包前置资产准备逻辑，创建 `build/desktop/staged_themes`，深度剔除外置主题母本中包含的 `node_modules` 与临时构建产物，将原本高达 **1.1 GB** 的臃肿资源包物理压减至 **11.87 MB**，构建耗时由数十分钟缩短至 40 秒；
* **原生 macOS DMG 镜像自动生成**：原生调用 macOS 底层 `/usr/bin/hdiutil`，自动注入 `/Applications` 软链接与修复脚本，产出开箱即用的标准磁盘镜像。

### 3. 跨平台免安装启动器生态一致性审计
* **四大启动脚本无缝对齐**：全面审计并对齐 `start.command` (macOS)、`start.sh` (Linux)、`start.bat` (Win CMD)、`start.ps1` (Win PowerShell) 与 `publish.sh`；
* **消灭闪退死穴**：在 `start.command` 中增加异常退出拦截逻辑，双击发生异常时终端常驻保留错误详情，彻底消除黑屏闪退；
* **Rule 4 静默安全合规**：所有脚本执行 `pip install` 时强制追加 `--disable-pip-version-check`；
* **新增 7 项自动化测试**：引入 `tests/test_launchers_consistency.py`，物理断言四大启动器在端口、版本门禁、虚拟环境优先级与入口契约上的一致性。

### 4. 社交媒体与图文矩阵分发排版加固
* **多源图片提取与维基图片自愈**：小红书（Xiaohongshu）适配器全面支持从 `cover` 相对路径、Markdown 图片、HTML 图片与 Obsidian 维基双链（`![[image.png]]`）中提取并自动转换为公网绝对 URL；
* **移动端 Emoji 导向微排版**：小红书正文自动剔除代码块残渣，多级标题智能转译为亲和高点阅率的 Emoji（`📌 `、`💡 `、`✨ `），标题严格遵守 ≤20 字符截断；
* **精细化流控锁**：将大耗时网络 I/O 移出互斥锁临界区，避免高并发下线程长时间互锁。

### 5. 数字装订工坊全格式学术级排版实机闭环
* **科学公式数据流解耦**：彻底解决 Word 审校本中 `<m:oMath>` 公式丢失的隐患。在全卷收集器中实现原始 Markdown 与编译后 MathML 的严格分离；
* **三大格式实机自测验证**：
  * **EPUB 3.0**：完整嵌入 W3C MathML `<math display="block">` 矢量语义标记；
  * **Word 审校本 (.docx)**：完整编译为微软官方原生可编辑 `<m:oMath>` (OMML) 公式对象；
  * **印刷级 PDF**：实测生成对开双面编排、页码印章（Folio Stamp）与分卷打印。

### 6. 全站静态托管发布流水线端到端闭环
* **Netlify CLI npx 自动降级**：实现 Netlify CLI 本地存在性探测与 `npx -y netlify-cli` 自动安全降级，彻底消除环境缺少全局 CLI 时的发布崩溃；
* **主站优先与批次账本**：全站托管部署严格遵循 `primary_hosting_id` 主站优先投递契约，实时记录部署流水日志与公网访问映射。
