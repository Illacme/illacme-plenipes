## 🛡️ 首次打开遇到安全提示？别担心，3 秒快速解决

因为我们是独立的开源公益项目，尚未购买商业巨头每年数千元的高昂签名证书，苹果与微软系统在首次打开时会按惯例弹出安全拦截或警告。软件 **100% 运行在您的本地电脑上，零任何隐私上传，绝对安全可靠**。

遇到以下提示时，请按对应指引轻松放行：

### 🍎 苹果 Mac 首次打开提示“无法打开”或“已损坏”
* **方法 1（最推荐，一键自动修复）**：  
  在下载的 DMG 安装盘或解压包中，找到并**直接双击运行「双击修复无法打开.command」**脚本。它会自动为您解除苹果系统的安全隔离，全程无需手动输入任何代码！
* **方法 2（访达右键打开）**：  
  进入“访达” ➔ “应用程序”文件夹，**按住键盘上的 Control 键，鼠标右键点击** `Illacme-Plenipes.app`，在弹出的菜单中点击“打开”，随后弹出的确认框中再次点击“打开”，以后便可正常双击启动。

### 🪟 微软 Windows 首次打开弹出蓝色“Windows 已保护你的电脑”
* 别紧张，直接点击蓝色弹窗里下划线文本 **“更多信息”**；
* 随后窗口右下角会出现 **“仍要运行”** 按钮，点击它即可正常打开。

## ✨ 本次 v1.8.0 带来了哪些重要升级？

### 1. 客户端安装包“超级瘦身”：体积减少 98%，下载秒开
* **以前的痛点**：过去打包时附带了许多网页模板的开发中间文件，导致安装包高达 1.1GB，下载慢、占硬盘；
* **现在的体验**：经过深度提纯与整理，纯净模板体积缩减到仅 **11.87 MB**！下载仅需几秒钟，解压启动轻盈迅捷。

### 2. 苹果 Mac 原生 DMG 安装镜像与启动体验优化
* **一拖即装**：Mac 用户现在拥有了最地道的 DMG 拖拽安装盘，像安装日常软件一样方便；
* **告别窗口闪退**：如果您习惯使用免安装脚本启动（如 `start.command`），现在即使遇到环境问题，终端窗口也会常驻保留友好的文字提示，再也不会突然黑屏闪退。

### 3. 专业排版无损导出：公式、代码、图表再也不错位
* **公式不再变乱码**：如果您写过包含数学公式（如薛定谔方程、质能方程）的学术文章，导出 Word 或电子书往往容易符号崩塌。现在数字装订工坊全线打通：
  * **导出 Word 审校本 (.docx)**：公式直接转为 Word 原生可编辑数学公式，可以直接在 Office 里双击修改；
  * **导出 EPUB 3.0**：符合国际 W3C 标准矢量数学排版，各大电子书阅读器均能高清渲染；
  * **导出印刷级 PDF**：自带优雅双面排版、专业页码印章与目录折叠，打印装订就像正规出版社出品。

### 4. 社交媒体一键美化排版：发小红书、发公众号更省心
* **小红书图文笔记自动提炼**：
  * **自动提取封面与插图**：不仅支持普通图片，还支持 Obsidian 双链图片（`![[图片.png]]`），自动整理为前 9 张卡片轮播图；
  * **手机端专属微排版**：枯燥繁琐的代码块自动收起为提示卡片，段落标题自动点缀俏皮生动的 Emoji 图标（📌 💡 ✨），长标题自动控制在 20 字以内，发布效果更吸睛；
* **微信公众号一键排版**：
  * 自动将文章里的外部网页链接转换为文末美观规整的“参考资料”脚注；
  * 代码块自动添加经典的 Mac 风格红黄绿圆点外壳，排版再也不会被微信后台吃样式。

### 5. 个人独立网站一键免费上线（GitHub / Vercel / Netlify）
* **无需购买云服务器**：点击“全站部署”，系统会自动帮您把整座数字文库编译为精美的个人独立网站，并免费部署到 GitHub Pages、Vercel 或 Netlify 上；
* **自动解决工具缺失**：电脑上就算没有预先安装部署工具，系统也会全自动在后台安全降级调用，让普通作者也能“一键发布，全球秒开”。

### 6. 系统版本号彻底规范统一
* 全面规范并统一为通用的语义化版本号 `v1.8.0`，消灭过去由于快速迭代留下的内部测试代号，让每一次功能升级与问题修复都清晰透明。
