# 🌌 01. 知识星谱与全局态势大盘 (Galaxy & Overview)

### 功能概述
**知识星谱** 是 Illacme Plenipes 的主视觉入口，基于 Three.js 与 3d-force-graph 构建，将您文库中的全部 Markdown 原稿、标签、分类以及语种副本映射为一个具备物理连通度的三维动态知识网络。

---

### 核心功能与操作

#### 1. 三维星系交互与 UnrealBloom 辉光
*   **漫游控制**：
    *   **左键拖拽**：旋转视角；
    *   **滚轮缩放**：放大/缩小星系视野；
    *   **右键平移**：整体平移星系中心。
*   **节点感应**：鼠标悬停在任意球体节点上，将实时高亮其反向链接（Backlinks）与语义关联路径，并弹出文章标题、语种与词频元数据卡片。

#### 2. HUD 导演视角巡航 (Director Mode)
*   点击星系右侧的 **HUD 导演控制器**，可自动开启电影级视轨巡航。
*   支持按文章更新时间轴或关联连通度进行聚焦特写，帮助创作者直观审视个人知识网络的结构演变与孤岛文章。

#### 3. 交付物与出版态势大盘 (Deliverables Dashboard)
*   **文库规模**：显示收录的原稿篇数、草稿篇数与总字数资产。
*   **出版产物**：统计当前已编译生成的 DOCX、PDF、EPUB 电子书数量。
*   **全域发布就绪度**：实时显示已激活的主站托管渠道与社交分发矩阵的健康状态。
