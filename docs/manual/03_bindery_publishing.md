# 📖 03. 出版装帧与数字排版 (Bindery Publishing)

### 功能概述
**出版装帧引擎 (The Bindery)** 负责将原稿提纯转化为印刷与数字出版物，支持面向商业出版的多种格式排版编译。

---

### 核心支持格式

| 格式 | 特性与适用场景 |
| :--- | :--- |
| **DOCX (Word / WPS)** | 原生 OMML 矢量数学公式（非图片）、代码语法彩色高亮、双语并排对齐表格，适合提交期刊、学术审阅或出版社初稿。 |
| **PDF (高清印刷物)** | 防折页版心校准、奇偶页对页排版、深层目录（Deep TOC）、多语言版权页（Colophon）。 |
| **EPUB (移动电子书)** | 流式排版，完美兼容 Apple Books、Kindle、微信读书及各种电子墨水屏阅读器。 |
| **WebBook (静态微书)** | 单纯、极速的离线网页微书，适合本地阅读与离线分发。 |

---

### 关键高级选项

*   **双语对照排版 (Polyglot Parallel)**：
    *   开启后，系统在组装 DOCX / PDF 时，自动将主语言与目标翻译语言按段落并排渲染，适合语言学习材料、跨国合同与技术标准文档。
*   **二维码穿透诊断 (QR Diagnostic)**：
    *   在纸质书或 PDF 中自动嵌入指向该文档公网最新在线地址的动态二维码，读者手机扫码即可查看最新修正或互动评论。
