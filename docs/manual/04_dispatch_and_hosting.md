# 🚀 04. 发布中心与静态托管 (Dispatch & Hosting)

### 功能概述
**发布中心** 是全站托管部署与多渠道社交媒体分发的统一指挥中心，通过高可靠的 SQLite 账本实时存证每一次发布的批次流水、文件差异与公网直达阅读链接。

---

### 核心功能与操作

#### 1. 全域发布任务大厅
*   **全站托管发布**：推流整站静态构建产物至您配置的托管云端（如 GitHub Pages、Vercel 等），同步更新全站搜索索引与目录结构。
*   **单文档发布存证**：当由单篇原稿触发时，账本精确标定为 `1 页` 与该文档的真实构建体积（如 `38.5 KB`），并在发布平台徽章上直接挂载该单篇文档的具体阅读 URL。

#### 2. 主站优先与备用镜像调度
*   系统严格遵循主权次序规则：
    *   **官方主站优先首发**：优先向您设定的主站平台（如 GitHub Pages）推送；
    *   **备用镜像随后推流**：主站完成后立即推送镜像节点（如 Vercel 或 Netlify），保证海外读者高可用访问。

#### 3. 发布历史账本 (Deploy Ledger)
*   **纯图标化微操作**：
    *   `📋`：一键唤出该次部署的打字机实时终端日志；
    *   `🔄`：一键按原参数再次发布（整站重发或单文档同步）。
*   **公网直达**：点击表格中的平台徽章（如 `GitHub Pages ↗`），直接在新标签页中打开已发布的线上页面。
