# 📂 02. 原稿文库与内容管理 (Content Vault)

### 功能概述
**原稿文库** 是创作者写作与资产管理的核心中枢。系统直连本地物理 Markdown 文件夹，具备严格的“**本地为真源、文库不上传**”主权安全底线。

---

### 核心功能与操作

#### 1. 物理目录树与状态识别
*   自动扫描 `vault_root` 下的多层级目录，支持递归解析。
*   **状态清晰标识**：
    *   `🟢 已发布 (Published)`：已成功部署或同步到外部渠道；
    *   `🟡 草稿 (Draft)`：包含 `draft: true` 或尚未执行分发的文档；
    *   `🟣 已翻译 (Translated)`：已生成多语种副本的文档。

#### 2. Markdown / 所见即所得 (WYSIWYG) 双模编辑
*   点击任意文档即可在中央编辑器中打开。
*   支持 **Markdown 纯文本源码模式** 与 **可视化实时排版模式**，支持语法高亮、表格、数学公式与任务列表。
*   **毫秒级自愈保存**：编辑过程中自动存盘，杜绝意外丢失。

#### 3. 单文档发布抽屉 (Vault Document Drawer)
*   在文档列表右侧点击 **「🌐 发布/分发」** 唤出专属抽屉：
    *   **网页托管发布**：勾选 GitHub Pages / Vercel 等平台，单篇原地推流并查看真实线上链接；
    *   **社交媒体分发**：选择微信公众号、知乎、Dev.to 等渠道，一键推流并转存插图；
    *   **实时态势卡片**：在抽屉底部实时滚动秒级推流耗时与控制台日志。
