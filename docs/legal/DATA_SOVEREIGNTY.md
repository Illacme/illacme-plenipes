# 🛡️ Illacme Plenipes 数据主权与内容所有权协议 (Data Sovereignty Policy)

**版本**：V1.0  
**生效日期**：2026年08月17日  

---

## 核心主权宣言 (Core Sovereignty Manifesto)

**Illacme Plenipes** 坚持 **“本地优先 (Local-First)”** 与 **“物理主权 (Physical Sovereignty)”** 的最高设计哲学。我们坚信：思想、原稿与出版物是创作者最宝贵的资产，技术工具应当赋能主权，而非剥夺主权。

---

## 1. 资产所有权确权 (Asset Ownership)

1.1 **原稿文库 (Manuscript Vault)**：  
- 您在本地存储的所有 Markdown 笔记、草稿、附图、音视频素材的知识产权与所有权 **100% 归属于您**。
- 本软件对原稿文库采用只读探测与本地增量分析机制，绝不修改您的原始思想文件，更不会将原稿私自上传至任何集中式云端。

1.2 **衍生出版物与构建产物 (Dist & Output)**：  
- 通过本软件编译、装帧生成的静态站点（HTML/CSS/JS）、RSS Feed、Sitemap 及多语言译文，其版权完全由您享有。
- 您有权将生成产物发布至任何您选择的私有服务器、托管平台或内容分发网络（CDN）。

1.3 **知识图谱与语义索引 (Semantic Weaving)**：  
- 本地构建生成的语义关联图谱、关键词权重与段落缓存账本（BlockShadowCache），均存储在您的本地磁盘（如 `.plenipes/` 目录），完全受您支配。

---

## 2. 零数据锁定与自由迁徙 (Zero Lock-in & Data Portability)

2.1 **标准开放格式**：  
- 系统原稿与输出严格遵循标准 CommonMark、GFM 与标准 Frontmatter 规范，不采用任何专有加密封装格式。
2.2 **可随时离开 (Right to Exit)**：  
- 无论您是停止订阅、更换设备还是停用本软件，您的原稿文件与历史发布记录均完好保留在本地文件系统中，可通过任何标准文本编辑器或静态站点生成器直接打开与迁移，无需经过任何专有导出解密手续。

---

## 3. 隐私边界与数据流向透明度 (Privacy & Data Flow Transparency)

3.1 **默认离线与零静默回传**：  
- 本软件在无网络连接状态下，具备完整的文库读取、语义检索、本地构建与数据导出能力。
- 本软件**绝不在后台静默传输您的文库内容、文件目录树或私人配置**。

3.2 **显式触发原则**：  
- 只有在您显式触发 **“AI 翻译/润色”** 或 **“矩阵分发发布”** 时，系统才会严格将当前任务所需的文段片段加密传输至您预先配置并授权的第三方 API 端点（如 OpenAI、DeepSeek、GitHub 等）。
