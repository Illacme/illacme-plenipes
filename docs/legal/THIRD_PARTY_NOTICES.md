# 📦 第三方开源组件致谢与许可证声明 (Third-Party Open Source Notices)

Illacme Plenipes 在构建过程中吸取了全球开源社区的卓越成果。以下列出本项目核心运行时所依赖的主要开源软件项目及其许可证信息。特此向这些优秀的开源作者与社区致以诚挚的敬意与感谢。
