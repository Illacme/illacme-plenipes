# 📚 场景三：一键装帧排版导出双语对照版 DOCX / PDF / EPUB 出版级电子书

### 📌 目标与收益
将文库中的系列文章或单篇长文，一键编译为具备专业出版级装帧质感的电子书产物：
* **DOCX 格式**：完美兼容 Microsoft Word / WPS，支持中英文双语并排对齐、原生 OMML 数学公式与彩色语法高亮代码块。
* **PDF 格式**：自动防折页版心校准、深层目录（Deep TOC）、双面印刷对页微调。
* **EPUB 格式**：支持主流移动阅读器（Apple Books、微信读书、Kindle 等）。

---

### ⏱️ 操作步骤（预计耗时：2 分钟）

#### 步骤 1：进入装帧书架
1. 进入工作台顶部导航 **「📂 原稿文库」**。
2. 在原稿列表上方，点击 **「📖 装帧书架 / 出版物中心」** 切换视图。

#### 步骤 2：配置书籍装帧参数
1. **选择母本风格**：选择学术简约、工业现代或古典藏书等排版样式。
2. **选择目标格式**：
   * 勾选 `DOCX`（多语种对照排版）；
   * 勾选 `PDF`（高清印刷物）；
   * 勾选 `EPUB`（流动版式电子书）。
3. **设置双语模式**：开启“双语对照排版 (Polyglot Parallel)”，系统将自动将原文与翻译后的目标语言并列渲染。

#### 步骤 3：一键装帧编译与下载
1. 点击 **「⚡ 启动装帧编译」**。
2. 后端排版引擎将在数秒内完成章节汇编、目录树生成、页眉页脚页码注入与公式排版。
3. 编译完成后，书架卡片上直接呈现 **「📥 下载 DOCX」**、**「📥 下载 PDF」**、**「📥 下载 EPUB」** 按钮，点击即可保存到本地。

---

### 💡 常见问题与避坑自愈

*   **Q: DOCX 中的数学公式变成乱码图片了吗？**  
    *A*: 没有。系统内置原生的 LaTeX ➔ OMML (Office Math Markup Language) 转换器，导出的是 Microsoft Word 原生矢量可编辑公式，绝非模糊位图。
*   **Q: 想要自定义书籍封面？**  
    *A*: 进入 **「🎨 设计中心」**，可以使用 AI 生图引擎（如 DALL-E / Imagen）或本地排版渲染器一键生成精美封面，并直接挂载到书籍元数据中。
