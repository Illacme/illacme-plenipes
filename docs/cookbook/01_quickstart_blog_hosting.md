# 🚀 场景一：将 Obsidian / 本地笔记一键发布为个人独立多语言博客

### 📌 目标与收益
将本地电脑上的 Markdown 文库（如 Obsidian、Logseq 或普通文件夹），全自动翻译为多语言版本，并一键推送到 GitHub Pages 或 Vercel 静态网站，拥有带搜索、暗黑模式与知识图谱的顶级个人主站。

---

### ⏱️ 操作步骤（预计耗时：3 分钟）

#### 步骤 1：启动工作台并关联文库
1. 双击根目录下的 **`start.command`**（macOS）或 **`start.bat`**（Windows）。
2. 浏览器自动打开工作台 `http://127.0.0.1:43212`。
3. 点击顶部导航 **「⚙️ 出版治理 -> 治理中心」**，选择 **「📂 存储适配」** 子标签。
4. 在 **原稿文库物理路径 (vault_root)** 中填入你存放笔记的绝对路径（如 `/Users/yourname/Documents/ObsidianVault`），点击保存。

#### 步骤 2：配置托管凭据（以 GitHub Pages / Vercel 为例）
1. 点击顶部导航 **「⚙️ 出版治理 -> 插件中心」**。
2. 找到 **GitHub Pages** 卡片：
   * 点击右上角 **「⚙️ 配置」**；
   * 填入您的 GitHub Personal Access Token；
   * *💡 极简向导*：如果您在本地终端已登录 `gh` 或 `git`，可直接点击 **「🔑 本地一键免密授权」**，系统将自动识别并回填账号！
3. （可选）同样方式启用 **Vercel** 作为备用镜像主站。

#### 步骤 3：一键全站发布
1. 点击顶部导航栏右上角的金色 **「🚀 全站发布」** 按钮（或进入「原稿文库」针对单篇文档点击发布）。
2. 在弹出的任务浮层中，系统将执行：
   * 自动解析文章 Frontmatter 标签与分类；
   * 自动调用 AI 模型进行语义分片多语言翻译；
   * 自动将静态网站产物推送至您的 GitHub Pages 仓库。
3. 部署完成后，在 **「发布中心」** 历史记录中直接点击 **`GitHub Pages ↗`** 徽章，即可秒级访问已上线的真实公网博客！

### 💡 常见问题与避坑自愈

*   **Q: 为什么卡片显示 `⚪ 待配置主机` 或复选框置灰不可勾选？**  
    *A*: 系统的中央凭据判决算子检测到该渠道缺少必要参数（如 GitHub Token 或 SFTP 主机地址）。点击卡片右上角直达设置抽屉，补齐必填项后将自动变为就绪态。
*   **Q: 静态网站发布后图片显示裂开？**  
    *A*: 前往 **「治理中心 -> 装帧与模式 -> 图像策略」**，确认已开启“资产自动本地化提取”；若使用外部图床，请在 **插件中心** 启用对应的图床插件（如 Cloudflare R2 或阿里云 OSS）。
