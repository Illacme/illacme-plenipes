# 🎨 场景四：为文章生成高质感 AI 封面与本地 OG 社交卡片

### 📌 目标与收益
文章内容写得极好，但在社交媒体分发（微信公众号、知乎、Dev.to 等）或静态网站首页展示时，如果没有抓人眼球的封面，打开率与传播度会大打折扣。  
**设计中心 (Design Studio)** 提供三态自适应引擎，满足不同创作者的视觉需求：
1. **本地极客 OG 卡片 (Local OG)**：无需配置任何 AI 密钥、完全离线，秒级渲染带极光弥散（Aurora Glow）、科技点阵与毛玻璃质感的 1200×630 社交分享封面；
2. **开源免版权图库 (Stock Photos)**：直连 Unsplash、Pexels、Pixabay，根据文章语义自动提炼关键词并一键挑选高清免版权实拍图；
3. **AI 创意意境生图 (AI Generation)**：接入 DALL-E 3、Google Imagen、Midjourney、Flux、智谱 CogView 等，根据文章自动推导 Midjourney 级创意 Prompt。

---

### ⏱️ 操作步骤（预计耗时：2 分钟）

#### 方式一：在「原稿文库」针对单篇文档精准定制（推荐）
1. 进入 **「📂 原稿文库」**，找到需要配图的文章。
2. 点击文档右侧的 **「🎨 封面设计」** 快捷按钮（或在分发抽屉中点击封面缩略图）。
3. 工作台自动跳转至设计中心，顶部出现常驻指示条：  
   `🎯 正在为文稿定制封面：《你的文章标题》 (docs/xxx.md)`。
4. **选择引擎并生成**：
   * **想要科技/架构风格**：选择 `本地渲染 (Local OG)` ➔ 确认标题与副标题 ➔ 点击 **「⚡ 立即渲染」**；
   * **想要自然/商务实拍图**：选择 `Unsplash` 或 `Pexels` ➔ 系统自动提取关键词（如 `technology minimal`）➔ 挑选心仪图片；
   * **想要超现实/艺术配图**：选择 `DALL-E 3` 或 `Flux` ➔ 系统自动生成提示词 ➔ 点击生成。
5. **一键应用与回填**：
   * 满意后点击 **「✅ 应用为此文封面」**，系统自动将封面图片下载落盘，并在该 Markdown 的 Frontmatter 中自动注入 `cover: assets/covers/...` 字段。
   * 点击顶部横幅的 **「↩️ 返回文库」**，瞬间回到写作或分发流程。

---

#### 方式二：在「设计中心」全局自由创作与批量装帧
1. 点击顶部导航 **「⚙️ 出版治理 -> 设计中心」**。
2. 在 **「🎨 创作工坊」** 中自由输入 Prompt 或关键词，自由创作多张视觉图片。
3. 切换至 **「🖼️ 视觉物权库 (Assets)」**：
   * 集中浏览、预览、下载历史生成的所有封面资产；
   * 支持一键将图片批量同步至已启用的云端图床（如 Cloudflare R2 / 阿里云 OSS）；
   * 支持针对某分类所有文章执行 **「🎲 随机视觉轮换」**，瞬间让整站告别千篇一律的素颜排版。

### 💡 常见问题与避坑自愈

*   **Q: 本地 OG 卡片中文标题有乱码或方块吗？**  
    *A*: 不会。后端内置了中文字体自愈探测链（自动检索系统的 PingFang SC、Hiragino Sans、Noto Sans CJK 与微软雅黑等），并内置自适应折行与安全边距保护算法，中文呈现优美清晰。
*   **Q: 开源图库搜索为什么提示 `Rate Limit`？**  
    *A*: Unsplash 等公开 API 在未填个人开发者 Key 时有每小时公共限流。建议在 **设计中心 -> 提供商管理** 中填入自己的免费 Unsplash Access Key，或直接切换为 `Pexels` / `Picsum` 引擎。
*   **Q: 生成的封面在微信公众号发文时会被压缩变形吗？**  
    *A*: 系统的社交分发管线在推送到微信公众号前，会自动执行比例校准与微信专属素材规范压缩，保证在手机端信息流中 2.35:1 与 1:1 两种卡片视角均清晰不裁切核心文字。
