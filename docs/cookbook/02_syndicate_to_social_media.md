# 🛰️ 场景二：单篇长文一键同步分发至微信公众号、知乎与 Dev.to 矩阵

### 📌 目标与收益
在本地 Markdown 写好一篇文章后，不想在各大平台反复排版、手动上传插图或因防盗链而报错。通过工作台，一次点击，瞬间同步至国内外主流技术社区与社交平台。

---

### ⏱️ 操作步骤（预计耗时：2 分钟）

#### 步骤 1：在插件中心激活目标渠道
1. 进入 **「⚙️ 出版治理 -> 插件中心」**。
2. 配置你要分发的平台：
   * **微信公众号**：填入 `AppID` 与 `AppSecret`，配置 IP 白名单后，文章将自动同步到**公众号素材库草稿箱**，排版格式优美且插图自动转存至微信永久素材库。
   * **知乎 / 掘金**：填入用户 Token 或 Cookie。
   * **Dev.to / Hashnode / Medium**：点击配置卡片中的 **「💡 Token 极简获取向导」** 魔术链接，直达个人 API 密钥申请页生成并粘贴。

#### 步骤 2：在原稿文库打开文章分发抽屉
1. 切换至顶部导航 **「📂 原稿文库」**。
2. 在文档列表中找到刚刚写好的文章，点击右侧的 **「🌐 发布/分发」** 按钮，唤出右侧操作抽屉。
3. 抽屉顶部选择 **「🛰️ 社交媒体全域分发」** 面板。

#### 步骤 3：挑选渠道并一键分发
1. 勾选需要投递的目标平台（如：微信公众号、知乎、Dev.to）。
2. （可选）在抽屉中切换语种预览，确认不同语言版本的文章标题与摘要。
3. 点击底部的 **「🚀 开始矩阵分发」**。
4. 系统将在后台并发执行：
   * Markdown AST 解析与清洗；
   * 插图图床转存与防盗链治理；
   * 目标平台 API 签名与投递。
5. 任务完成后，各平台卡片原地更新为 **`已发布`** 并提供文章后台直达链接。

---

### 💡 常见问题与避坑自愈

*   **Q: 微信公众号推送提示 `40164: invalid ip`？**  
    *A*: 微信官方要求调用接口的出口 IP 必须加入白名单。登录微信公众平台后台 -> 开发接口设置 -> IP 白名单，将本机公网 IP 添加进去即可。
*   **Q: 海外平台（如 Medium / Dev.to）需要规范的 Canonical URL（防 SEO 惩罚）？**  
    *A*: 系统会自动读取该文章在您个人官方网站（如 GitHub Pages）上的永久地址，并在向 Medium / Dev.to 投递时自动写入 `canonical_url` 元数据，确保搜索引擎将权重归于您的独立主站。
