## 2. 深度功能解析

### 2.1 物理拓扑约束 (Physical Topology)
*   **社区版**：强制执行“原稿根目录 -> 主题源目录”的 1:1 映射。系统在同步阶段会拦截任何非空的 `source` 或 `prefix` 配置，并强制重置为根路径。
*   **专业版**：支持复杂的物理路径重对正，允许将原稿仓库中的特定子目录（Source）精确映射到主题的不同物理前缀（Prefix）。

### 2.2 编辑主权与方言 (Dialect Governance)
*   **社区版**：全球出版物共用一套 `default.yaml` 提示词模版。无法为特定频道（如 Blog、Docs、News）定制不同的翻译风格。
*   **专业版**：支持在 `route_matrix` 中为每个频道锚定独立的方言文件。工厂层会根据频道标识动态加载对应的物理资产（Style YAML）。

### 2.3 分发矩阵 (Distribution Matrix)
*   **社区版**：受“主权语种栅栏”限制，一次出版任务仅能同步产生一个目标语种的备份。
*   **专业版**：开启全量语种矩阵分发，单次“出版点火”可同时向全球数十个语种节点分发物理资产。
